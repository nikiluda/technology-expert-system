# Technology Expert System

Консольная экспертная система для подбора технологического стека **backend-приложения**.

Система анализирует ответы пользователя на набор вопросов о проекте и на основе базы знаний формирует рекомендации по нескольким категориям технологий:

* **Backend Language**
* **Database**
* **Message Broker**
* **Cache**
* **API**
* **Containerization**

В результате пользователь получает:

* рейтинг технологий внутри каждой категории;
* наиболее подходящую технологию для каждой категории;
* сформированный рекомендуемый **технологический стек**.
